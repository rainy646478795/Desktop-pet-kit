# Pet Maker

用你真实的猫猫照片或视频，生成一只「照片抠图风格」的桌面宠物小猫，并配上 Cat Bubble 侧车：歪头待机、语录气泡、鼠标交互、可选 Codex 授权气泡。

这套流程的核心风格是**照片抠图**：宠物形象来自真实猫咪照片/视频的透明抠图，不是动漫、卡通、插画或 AI 绘制的小猫。喜欢真实照片质感的人适合用这套流程。

## 一、这套 Skill 能做什么

1. 根据你提供的猫猫照片/视频，切出宠物图集（idle、跑、跳、挥手、等待、16 方向视线）
2. 组装成 Codex v2 宠物并安装到 `~/.codex/pets/<猫名>/`
3. 生成 Cat Bubble 桌面侧车：透明置顶、语录气泡、鼠标触发动作
4. 全程给你省 Token 的替代方案：你提前抠好图，就不需要 AI 生成和逐帧重做

## 二、最省 Token 的用法（推荐）

你自己先完成最贵的一步：**抠图**。AI 生成图片和逐帧审查是 Token 消耗最大的环节，你提前提供透明 PNG，可以省掉大部分。

### 自己抠图的三种方式

| 方式 | 准备内容 | 省 Token 程度 |
| --- | --- | --- |
| 透明 PNG 直接给我 | 每张图已经是去背景的 `RGBA` PNG，猫占画面主体 | 最省 |
| 绿幕视频/照片 | 猫在纯绿幕或纯色背景前，全身清晰 | 很省 |
| 原始照片/视频给我 | 没抠图，由流程帮你抠 | 最费，但也能做 |

### 还省 Token 的地方

- 照片和视频自己拍好、自己先裁剪，不要发一大堆废片
- 一次发「全身正面 + 全身侧面 + 全身背面 + 尾巴独立可见」各一张，不要发几十张重复图
- 用接触板（contact sheet）批量审查，不要让 Agent 一张张打开大图
- 所有确定性步骤用脚本跑（切帧、组装图集、去绿幕、校验）
- 每一步结论写进 `run-summary.json` / checklist，续跑不要重读原始素材
- Cat Bubble 默认本地语录、零 API，不开 `--live-model`

## 三、拍猫的素材要求

拍得对不对，决定宠物能不能做出来。

### 必须能看到全身

- 猫要完整入镜：头、身体、四条腿、尾巴都要在画面里
- 只拍头、只拍半身、尾巴被裁掉、四肢被遮住的图，**不能**用来生成宠物 idle 图集
- 猫要占画面主体，周围留少量背景即可

### 建议拍摄清单

| 用途 | 建议拍法 |
| --- | --- |
| 正面站姿 | 猫正对镜头，四脚着地，尾巴自然垂在一侧 |
| 侧面站姿 | 猫侧身，能看到身体轮廓和尾巴走向 |
| 背面站姿 | 从后侧拍，能看到背部毛色和尾巴根部 |
| 走路 | 侧面跟拍或慢镜头，拍猫左右迈步 |
| 跳跃 | 拍起跳、腾空、落地三个时刻 |
| 挥手/抬爪 | 正面拍抬前爪，爪子和身体不重叠 |
| 眨眼/歪头 | 正面近距离拍，眼睛大而清晰 |

### 拍摄环境

- 纯绿幕最好；没有绿幕就选纯色、无杂物的背景，方便抠图
- 光线均匀，不要在猫身上形成大面积阴影或反光
- 不要糊、不要抖，优先 1080p 以上
- 一个动作多拍几秒视频，比单张照片更好用

## 四、需要装 Codex / Agent 吗

### 最终运行 Cat Bubble：不需要

编译好的 Cat Bubble 是独立 macOS 应用：

- 不需要 Codex
- 不需要 GPT
- 不需要 Agent
- 不需要联网（默认本地语录）

只要一台 Apple Silicon Mac（macOS 15+）就能跑。

### 生成宠物和定制：有 Agent 更方便

让 Agent 帮你走完整流程，省去手敲脚本：

- 任何能读写文件、执行 Python/Swift 构建命令的 Agent 都可以
- 不限定 GPT，不限定 Codex
- 只有「Codex 授权气泡」这个可选功能需要本机安装 Codex

## 五、完整流程

1. 拍素材（见第三节）
2. 选择省 Token 模式：自己抠透明 PNG，或给绿幕素材
3. Agent 切帧 → 组装图集 → 去绿幕 → 校验 → 打包到 `~/.codex/pets/<猫名>/`
4. 生成 Cat Bubble 侧车（见 [cat-bubble-skill](../cat-bubble-skill/README.md)）
5. 你调语录、速度、快捷键、触发方式

## 六、风格说明

- 本流程固定使用**照片抠图风格**：保留真实猫咪的毛色、纹路、质感
- 不做动漫化、不做圆润玩偶化、不改成插画
- 图集尺寸统一 `192x208` 单元格，但内容仍以真实照片质感为准
- 如果你想要动漫/玩偶风格，这套 Skill 不适用，应该走 hatch-pet 的生成式风格流程
